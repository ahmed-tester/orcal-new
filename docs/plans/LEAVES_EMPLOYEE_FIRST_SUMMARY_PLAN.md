# خطة تنفيذ: شاشة الإجازات والأرصدة بنمط «الموظف أولاً» (Leaves Summary & Balances)

> **التاريخ:** 2026-11-10  
> **المرجعية:** المعيار الموحد المعتمد في `docs/plans/ATTENDANCE_EMPLOYEE_FIRST_AND_UX_UNIFICATION_PLAN.md` و [حصر الشاشات](MODULES_REQUIRING_ATTENDANCE_SUMMARY_PATTERN.md).  
> **الهدف:** تحويل شاشة الإجازات `/leaves` من جدول حركات مسطح إلى لوحة ملخص قائمة على الموظف (Employee-First)، مع بطاقات KPI علوية، فلاتر موحدة، نافذة تفاصيل تفاعلية (Modal) لاستعراض وطباعة رصيد وسجل إجازات الموظف، وفصل الجدول الخام إلى `/leaves/detailed`.

---

## 1. الملخص التنفيذي للمقارنة

| البند | الوضع الحالي | الوضع المستهدف |
|---|---|---|
| **شاشة الفهرس `/leaves`** | جدول مسطح في `LeavesTable`: سطر لكل طلب إجازة فردي | جدول **سطر واحد لكل موظف** يوضح: الرصيد السنوي، المستحق، المستهلك، المتبقي، وموقف الموظف اليوم |
| **بطاقات KPI العلوية** | لا توجد بطاقات إحصائية في الصفحة | **5 بطاقات KPI** تفاعلية: (إجمالي الموظفين، في إجازة اليوم، طلبات معلقة، أيام مستهلكة، رصيد متبقي إجمالي) |
| **استعراض إجازات الموظف** | لا يوجد؛ يتطلب فلاتر أو دخول فردي | **نافذة تفاعلية (Modal)**: بطاقات الرصيد، سجل إجازات الموظف التاريخي، زر طلب إجازة فوري، زر طباعة كشف |
| **السجل الخام القديم** | هو الشاشة الرئيسية الوحيدة | يُنقل إلى مسار مستقل `/leaves/detailed` مع الاحتفاظ بكافة فلاتره وتبويباته الحالية |
| **الطباعة والتصدير** | طباعة نموذج طلب فردي فقط | **طباعة كشف إجازات موظف رسمي (A4 RTL)** + **طباعة ملخص الفلاتر** + **تصدير CSV مع BOM** |
| **طبقة الخدمات** | العمليات في `LeaveBalanceService` فقط | إضافة `LeaveSummaryService` للتجميع وحساب المؤشرات وعزل الشركات عبر `CompanyAccessScopeService` |

## 2. المعمارية والملفات المتأثرة

```
┌────────────────────────────────────────────────────────┐
│ 1) LeavesSummary.php + leaves-summary.blade.php        │
│    (لوحة الملخص: بطاقات KPI + الفلاتر + جدول الموظفين)   │
├────────────────────────────────────────────────────────┤
│ 2) LeaveSummaryService.php                             │
│    (استعلامات التجميع، حساب الأرصدة، ونطاق الوصول)     │
├────────────────────────────────────────────────────────┤
│ 3) Modal نافذة تفاصيل إجازات الموظف                     │
│    (بيان الأرصدة وسجل الإجازات وأزرار الإجراءات)       │
├────────────────────────────────────────────────────────┤
│ 4) LeavePrintController.php + قوالب الطباعة            │
│    (كشف حساب إجازات موظف + طباعة ملخص النتائج)         │
├────────────────────────────────────────────────────────┤
│ 5) ListLeaves.php (/leaves/detailed)                   │
│    (الجدول التاريخي القديم بكافة تبويباته)              │
└────────────────────────────────────────────────────────┘
```

### خريطة الملفات:
1. `app/Services/LeaveSummaryService.php` (**جديد**): التجميع الإحصائي والأرصدة وعزل الصلاحيات.
2. `app/Filament/Resources/Leaves/Pages/LeavesSummary.php` (**جديد**): صفحة الملخص الرئيسية.
3. `resources/views/filament/resources/leaves/pages/leaves-summary.blade.php` (**جديد**): واجهة العرض التفاعلية.
4. `resources/views/leaves/employee-statement-print.blade.php` (**جديد**): قالب كشف إجازات الموظف للطباعة المتوافقة مع المتصفح A4 RTL.
5. `resources/views/leaves/summary-print.blade.php` (**جديد**): قالب طباعة ملخص النتائج لجميع الموظفين.
6. `app/Filament/Resources/Leaves/LeaveResource.php` (**تعديل**): تعديل المسارات: `index` للملخص، و `detailed` للجدول القديم.
7. `app/Filament/Resources/Leaves/Pages/ListLeaves.php` (**تعديل**): إضافة زر `summaryView` للعودة للملخص.
8. `app/Filament/Resources/Leaves/Pages/CreateLeave.php` (**تعديل**): دعم التعبئة المسبقة لمعرف الموظف من الرابط `?employee_id=`.
9. `app/Http/Controllers/LeavePrintController.php` (**تعديل**): إضافة دوال طباعة كشف الموظف وملخص الفلاتر.
10. `routes/web.php` (**تعديل**): تسجيل مسارات الطباعة الجديدة داخل مجموعة `auth`.
11. `lang/ar/leaves.php` و `lang/en/leaves.php` (**تعديل**): إضافة كافة الترجمات المتطابقة تحت قسم `summary.*`.
12. `tests/Feature/LeaveSummaryServiceTest.php` (**جديد**): اختبارات Feature للتجميع والأرصدة والنطاق.

## 3. خطوات التنفيذ المنهجية

1. **الخطوة 1: بناء خدمة التجميع `LeaveSummaryService`**
   - استعلام مجمّع يربط الموظفين `employees` بحركات الإجازات `leaves`.
   - حساب إجمالي الأيام المستهلكة (السنوية وغيرها)، الرصيد السنوي المتاح من `LeaveBalanceService`، وحالة الموظف اليوم.
   - تطبيق `CompanyAccessScopeService::apply($query)` لتأمين عزل الشركات والفروع.
   - توفير دوال المؤشرات `getStats()`، وتفاصيل الموظف `getEmployeeLeaveDetails()`، والتصدير `exportRows()`.

2. **الخطوة 2: إنشاء صفحة الملخص `LeavesSummary` ومكوناتها**
   - إدارة حالة الفلاتر (السنة، الشركة، الفرع، حالة العمل، حالة الإجازة، البحث).
   - دوال فتح وإغلاق النافذة المنبثقة `openDetails($employeeId)`.
   - فرز الأعمدة التفاعلي والتنقل بين الصفحات.

3. **الخطوة 3: تصميم الواجهات (Blade Views)**
   - واجهة الملخص `leaves-summary.blade.php` متطابقة في أناقتها مع واجهة الحضور.
   - النافذة المنبثقة (Modal) الغنية ببطاقات الرصيد وتاريخ الإجازات.
   - قوالب الطباعة الأنيقة النظيفة (RTL A4).

4. **الخطوة 4: تحديث مسارات المورد وكنترولر الطباعة**
   - ربط `LeaveResource` بالمسار الجديد.
   - تحديث `ListLeaves` و `CreateLeave`.
   - تسجيل المسارات في `routes/web.php` و `LeavePrintController`.

5. **الخطوة 5: الترجمة الكاملة**
   - كتابة كافة المفاتيح في `lang/ar/leaves.php` و `lang/en/leaves.php`.

6. **الخطوة 6: الفحص والاختبارات والتسليم**
   - فحص `php -l`، `view:clear`، و `vendor/bin/pint`.
   - كتابة وتشغيل Feature Tests.
   - تحديث التوثيق وسجل التغييرات.
