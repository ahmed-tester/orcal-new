# خطة ملخص المخالفات وسدادها حسب الشركة

**الحالة:** جاري التنفيذ. **تاريخ بدء التنفيذ:** 2026-11-11 على `dev`.

## 1. السلوك الحالي لموديول المخالفات

- [مورد المخالفات](../../../app/Filament/Resources/Violations/ViolationResource.php) يفتح مباشرة قائمة جدولية فردية لكل مخالفة (`ListViolations`) في `/violations`.
- حركات وسندات سداد المخالفات مسجلة في [مورد مستقل](../../../app/Filament/Resources/ViolationTransactions/ViolationTransactionResource.php) عبر موديل `ViolationTransaction` المرتبط بالمخالفة عبر `violation_id`.
- موديل المخالفة `Violation` يحسب الأصل (`violation_amount`) والمسدد (`paid_amount`) والمتبقي (`remaining_amount`) وتحديث حالة السداد (`payment_status`) ومراحل المخالفة (`stage`).
- الطباعة الحالية للمخالفات تعتمد على تصدير عام لقائمة المخالفات عبر `ExportPdfController`، ولا يوجد كشف حساب مالي تفصيلي للمخالفات مجمع حسب الشركة، ولا نافذة منبثقة تفاعلية للملخص.

## 2. التغيير المقترح (مطابقة معمارية موديول الديون)

1. **الصفحة الرئيسية (`/violations`):**
   - تحويل مسار `index` إلى صفحة مخصصة: `ViolationsSummary`.
   - توفير 5 بطاقات KPI إحصائية علوية:
     - إجمالي الشركات/الجهات.
     - عدد المخالفات.
     - إجمالي المبالغ.
     - المبالغ المسددة.
     - المبالغ المتبقية.
   - شريط الفلاتر الموحد (`x-filter-bar`) بدعم الفلترة المتعددة: الشركة، الفرع، التصنيف، النوع، حالة السداد، النطاق الزمني، والبحث.
   - تصدير إكسيل/CSV مباشر للملخص المفلتر، وزر طباعة الملخص.

2. **التجميع المالي في الملخص:**
   - تجميع المخالفات على مستوى **الشركة (`company_id`)** لحساب:
     - عدد المخالفات لكل شركة.
     - إجمالي قيمة المخالفات.
     - إجمالي المسدد.
     - إجمالي المتبقي.
     - إجمالي المتأخر/المتجاوز للمهل القانونية.

3. **كشف الحساب التفاعلي (Slide-over Modal):**
   - عند النقر على اسم الشركة في جدول الملخص، يُفتح كشف حساب جانبي تفصيلي يعرض:
     - بيانات الشركة الإجمالية.
     - تفاصيل كل مخالفة (رقم المخالفة، رقم السجل الخارجي، التصنيف، النوع، جهة الإصدار، التواريخ والمهل، والمبالغ).
     - جدول حركات السداد (`ViolationTransaction`) المسجلة على كل مخالفة (رقم السند، التاريخ، المبلغ، الخزينة، نوع الحركة، والبيان).
     - زر مباشر «تسجيل سداد دفعة» لنقل المستخدم لإنشاء حركة سداد جديدة محددة مسبقاً بالمخالفة والشركة عند امتلاك الصلاحية.
     - زر طباعة كشف حساب الشركة الفردي.

4. **القائمة التفصيلية (`/violations/detailed`):**
   - نقل `ListViolations` الحالية إلى `/violations/detailed` مع إضافة أزرار التبديل السلس بين عرض الملخص والعرض التفصيلي.

5. **طبقة الخدمة الموحدة (`ViolationSummaryService`):**
   - توفير استعلامات آمنة مطبقة لنطاق الوصول والشركات المصرح بها (`CompanyAccessScopeService`).
   - `summaryQuery(array $filters)`
   - `stats(array $filters)`
   - `details(int $companyId, array $filters)`

6. **طباعة الملخص وكشوفات الحساب:**
   - توفير مسار مخصص للطباعة: `/violations/summary/print/{company?}` عبر `ViolationSummaryPrintController`.
   - توفير قوالب الطباعة المطابقة لقالب الديون:
     - `resources/views/violations/summary-print.blade.php`
     - `resources/views/violations/partials/summary-table.blade.php`
     - `resources/views/violations/partials/statement.blade.php`

7. **ملفات الترجمة (Localization):**
   - إضافة كافة المفاتيح في `lang/ar/violations.php` ومطابقتها في `lang/en/violations.php`.

## 3. التحقق ومطابقة القواعد

- فحص تركيب الكود: `php -l` على كل ملف يتم إنشاؤه أو تعديله.
- مسح الكاش: `php artisan view:clear`.
- تنسيق الأكواد: `vendor\bin\pint`.
- اختبار الاستعلامات وصلاحيات الوصول.
