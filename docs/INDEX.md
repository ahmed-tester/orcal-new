## كيف تتحدث المعرفة

- **دليل الوحدة:** السلوك الحالي وخريطة الملفات والقواعد والاختبارات ومتطلبات النشر. أضف دليلًا لوحدة جديدة عند فحصها، واستخدم الأدلة القائمة إن كانت كافية.
- **المرجع المشترك:** أسماء المكونات وكيفية إعادة استخدامها وروابط التفاصيل، دون نسخ كل دليل إليه.
- **سجل التغييرات:** لكل مهمة مؤثرة: التاريخ، ما تغير ولماذا، الملفات، التحقق الفعلي، حالة النشر، والمتبقي.
- **سجل المشكلات:** لكل مشكلة معرف ثابت، دليل وحالة وآخر تحقق. عند الحل حدّث نفس البند واربطه بسجل التغيير.
- **AGENTS.md:** قواعد مستمرة فقط، مثل ترتيب القراءة واشتراط الموافقة والتوثيق، وليس تفاصيل كل إصلاح.

في أي دليل جديد سجّل: تاريخ المطابقة، الغرض، نقاط الدخول، قواعد العمل، التبعيات المشتركة، التحقق وحدوده، والنشر. لا تضف دليلًا فارغًا لكل وحدة لم تُفحص بعد.

## معنى الحالات

| الحالة | الدليل المطلوب |
| --- | --- |
| مقترح | لم يُنفذ؛ موافقة أو قرار مطلوب |
| منفذ محليًا | التغيير موجود في ملفات المشروع المفحوصة |
| متحقق منه | نتائج فحوص محددة، بتاريخ وحدود واضحة؛ لا يعني اختبار النظام كله |
| منشور | تأكيد صريح من المستخدم أو تحقق مباشر من النسخة المنشورة يحدد نطاقه |

النشر يدوي بواسطة المستخدم. لا تحدّث حالة النشر تلقائيًا بعد تعديل ملف محلي. لا يوجد مراقب في الخلفية؛ التعديلات الخارجية أو تغيير الفرع قد يجعلان بعض المعلومات بحاجة لإعادة مطابقة. إن اختلفت الملفات عن تقرير سابق، سجّل الفرق أولًا ولا تسترجع ملفات المستخدم تلقائيًا.
