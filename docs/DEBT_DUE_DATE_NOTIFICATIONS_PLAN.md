# خطة تفعيل نظام تنبيهات استحقاق الديون ومتابعتها

## 1. الهدف
تفعيل نظام تنبيهات الاستحقاق والمتابعة للديون والسلف (`Debts & Installments`) بحيث يقوم النظام تلقائياً برصد الديون التي اقترب موعد استحقاقها أو حان موعدها أو تأخرت، وإرسال إشعارات مباشرة للموظف المحدد في حقل **"يصل التنبيه إلى"** (`notify_employee_id`)، وتضمينها في تقرير الإشعارات العام ولوحة التحكم.

---

## 2. خطوات التنفيذ

### 2.1 ربط الديون بخدمة التنبيهات المركزية (`NotificationAlertsService`)
- إضافة رصد الديون النشطة غير المسددة (`Debt`) ذات تواريخ الاستحقاق (`due_date`):
  - حساب الأيام المتبقية (`daysRemaining`).
  - تحديد درجة الأهمية:
    - متأخرة (`overdue` إذا كانت الأيام سالبة).
    - حرجة وعاجلة (`critical / urgent` إذا تبقت 7 أيام أو أقل).
    - تنبيه مبكر (`warning` إذا تبقت 30 يوماً أو أقل).
  - توجيه التنبيه للموظف المحدد في `notify_employee_id` أو مالك المنشأة.
  - إرفاق نص المتابعة المكتوب في `notification_notes` ورقم الدين والمبلغ المتبقي.
- تحديث إحصائيات تقرير الإشعارات (`getSummaryCounts`).

### 2.2 إنشاء أمر مجدول لفحص الديون وإرسال إشعارات قاعدة البيانات (`CheckDebtDueDatesCommand`)
- إنشاء الأمر: `app/Console/Commands/CheckDebtDueDatesCommand.php`:
  - التوقيع: `debts:check-due-dates {--days=7}`.
  - يقوم يومياً بفحص الديون المستحقة أو المتأخرة.
  - تحديث حالة الدين تلقائياً إلى `overdue` إذا حل تاريخ الاستحقاق ولم يُسدد.
  - إرسال إشعار قاعدة بيانات (Filament Database Notification) للموظف المسؤول (`notifyEmployee->user`) يظهر في جرس الإشعارات، متضمناً رقم الدين، المستفيد، المبلغ المتبقي، ونص التنبيه والمتابعة، وزر للانتقال المباشر للدين.
- تسجيل الأمر في `routes/console.php` ليعمل يومياً في تمام الساعة 10:00 صباحاً.

### 2.3 إجراءات الإرسال اليدوي الفوري (Manual Actions)
- إضافة زر إجراء `send_notification` في جدول الديون (`DebtsTable.php`) وفي صفحة التعديل (`EditDebt.php`).
- يتيح إرسال تنبيه متابعة فوري إلى جرس إشعارات الموظف المحدد (`notifyEmployee->user`) مع طلب تأكيد.
- يتضمن رابط مباشر لعرض الدين وتفاصيله ونص الملاحظات.

### 2.4 الترجمة واللغة
- إضافة النصوص في `lang/ar/debts.php` و `lang/en/debts.php` لعناوين الإشعارات ورسائل التذكير وتأكيدات الإرسال.
